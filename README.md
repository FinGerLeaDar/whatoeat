# 退休投資規劃 Dashboard

免費、免登入、可放在 GitHub Pages 的靜態網頁。適合自行調整退休投資假設，例如初始本金 US$10,000、每月定投、年化回報、通脹、每 1/3/5 年 Review 加供，以及退休後提取比例。

## 檔案
- `index.html`：頁面結構
- `style.css`：樣式與手機版版面
- `app.js`：所有計算及圖表（不需要 API）

## 本機使用
下載整個資料夾，直接雙擊 `index.html` 即可用瀏覽器開啟。無需安裝、管理員權限、登入、API Key 或付費服務。

## 放上 GitHub Pages
1. 在 GitHub 建立一個 repository。
2. 將 `index.html`、`style.css`、`app.js` 和 `README.md` 上傳到 repository 根目錄。
3. 進入 repository 的 **Settings → Pages**。
4. 在 Build and deployment 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/(root)`，按 Save。
6. 等 GitHub Pages 完成部署，再開啟顯示的網站網址。

## 計算方法與限制
- 以每月複利模型估算：每月先按月回報率增長，再加入當月供款。
- 年化回報換算為月回報：`(1 + annual_return)^(1/12) - 1`。
- Review 到指定年期時，按設定金額增加每月供款，並受月供上限限制。
- 「今日購買力」以輸入的通脹率折算。
- 退休後提取金額為退休資產 × 提取比例 ÷ 12。這不是保證收益，也不等於每年投資回報。
- 現金預測只計目前現金 + 每月儲蓄 × 年數，不計利息、支出變化或突發開支。
- 沒有 API、帳戶連線、追蹤器或後端；資料只在當前頁面計算，不會上傳到伺服器。

## 重要提醒
此工具只作教育及情境規劃，不是投資、法律或稅務建議。市場回報會波動，可能損失本金。實際稅務、基金費用、匯率、股息預扣稅及遺產安排需自行核實。
